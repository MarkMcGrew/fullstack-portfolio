## Featured Projects

### 1. [Emergency Medical QR Profile App](./ems-health-app)
A full-stack emergency triage web application designed to give paramedics and first responders immediate access to critical patient medical records via a scannable QR code.
- **Highlights:** Dynamic PNG QR code generation (`phpqrcode` & GD Library), read-only public triage screen, PIN-protected profile editing, and a `@media print` credit-card-sized emergency wallet card.
- **Tech Stack:** PHP, MySQL, HTML5, CSS3, JavaScript

### 2. [GPA & Degree Progress Tracker](./gpa-tracker)
An interactive academic tracking dashboard built to manage coursework, calculate weighted 4.0 plus/minus GPAs, and track progress toward a 120-credit graduation milestone.
- **Highlights:** Full CRUD operations with persistent MySQL storage, support for decimal credit conversions (e.g., `2.67`), transfer credit (`TR`) handling, and a real-time visual progress bar.
- **Tech Stack:** PHP, MySQL, JavaScript, HTML5, CSS3
